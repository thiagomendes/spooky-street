# Decisions log

Items marked **Owner** need the owner's confirmation.

| ID | Decision | Why | Revisit when |
|---|---|---|---|
| D1 | Pin **Unity 6000.3.28f1** (Unity 6.3 LTS) via `unityci/editor:ubuntu-6000.3.28f1-{base,ios}-3`, pinned by digest. | Newest 6.3 patch with a mature GameCI image-v3 build (2026-11-03). 6000.3.29f1 exists only as image v4, published 2 days before S000. | A newer 6.3 patch is needed; bump ProjectVersion, both image tags and digests together (validator enforces the match). |
| D2 | Run the GameCI editor image directly from `ci/unity/run-unity.sh` instead of `game-ci/unity-builder` / `unity-test-runner`. | Builder v4 runs on the deprecated Node 20 runtime; v5+/test-runner v4.4 download an unpinned CLI (`cliVersion: latest`). | D3 | Localization uses engine-free **semantic-key JSON string tables** (`StringTable`, `LocalizationCatalog`, pseudo-locale) instead of Unity Localization tables in S000. **Owner** | The spec lists Unity Localization in the stack, but its tables cannot be authored without the editor and its Addressables-based remote tables do not natively provide the spec's integrity-hash, staged, atomic pack activation. The key/fallback contract is what S000 needs and is unit-tested. | S004 language packs: either keep custom packs or add a Unity Localization adapter behind `LocalizationCatalog`. |
| D4 | **Addressables not installed yet.** | Nothing loads remotely before S004; adding it now would add a required content build step to every export with no consumer. | S004. |
| D5 | The S000 world, Pip, camera rig and UI are **built from code** by `GameBootstrap`; the scene holds one object. | No editor in the cloud session. Hand-authored YAML is limited to small, validated files. Everything is replaceable when the block is authored (S001). | S001 block-out (likely via the optional GPU workstation or prefabs). |
| D6 | Build number = `<run_number>.<run_attempt>`, set on macOS per attempt. Marketing version = `bundleVersion` in ProjectSettings (0.0.1). | Unique per retry, maps a TestFlight build straight to its workflow run. | Workflow file renamed (run numbers restart) — then raise `bundleVersion`. |
