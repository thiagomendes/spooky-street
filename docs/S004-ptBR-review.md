# S004 D2: Brazilian Portuguese, owner review

Every user-facing line of `pt-BR.json` beside its English, grouped by screen and character, for the owner
(about an hour). Branch `feature/s004-ptbr`, evidence in `docs/S004-ptbr.md`. This page is generated by
`tools/l10n/review_page.py` from both tables, so it shows the shipped text exactly.

- **Len** is the Portuguese length and the budget: the English text through the pseudo-localizer (+35 % plus two
  brackets). Screen layouts are proven against that budget in the visual captures. Every line fits, and a Core
  test enforces it.
- **UNSURE** marks wording I would most like the owner to check. The other notes explain choices.
- Names: Candlebrook, Pip, Bea, June and Kit are kept. Lantern Lane = Rua das Lanternas, Aunt Kit = Tia Kit and
  Mr. Vale = Sr. Vale (open decision 2a). Pip is a girl, so lines addressed to her use feminine forms ("você
  mesma", "bem-vinda").
- Register: the UI and the radio use the standard você imperative ("Siga", "Escute", "Segure"). The
  characters speak informal Brazilian ("Vem", "Escuta", "Me dá uma mão?"), except Mr. Vale, who is polite
  and old-fashioned ("Sente-se", "Eu a via", "jamais").
- Hints say exactly as much as the English, and the conclusion lint checks them in Portuguese.
- To change a line, edit `Assets/SpookyStreet/Content/Resources/Localization/pt-BR.json` (its key) and
  `docs/playtest/c01-playtest-kit.pt-BR.md` Appendix A if the line is there.
