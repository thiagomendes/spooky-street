# S000.3: UI language in game

Branch `feature/s000.3-ui-language`. Source of truth for the design: `docs/ui-language.md` (art bible v2 §6).

## What changed

- **Baked sprites.** `tools/ui_mock/ui_mock.py --export` writes 19 sprites into `Resources/UI/`, about 724 KB in plain
  git:
  - felt discs, paper card and tag, orange felt button, tiled running stitch, stick chevron;
  - the stitched logo;
  - nine icons.

  Contact sheet: `docs/evidence/s000.3/ui_sprites_contact_sheet.jpg`.
- **Import rules.** `Core/Art/UiSpriteCatalog.cs` holds the sprite names and 9-slice borders. `Editor/UiSpriteImportRules.cs`
  forces every sprite to import as a 2D Sprite with no mipmaps and ASTC on iOS.
- **Screens.** `GameUi` now uses `CraftButton` and `UiSprites`:
  - Title: stitched logo, case name on paper, and a single orange primary action. Continue appears in orange once a save
    exists, through the `SetHasSave` hook.
  - HUD: night felt discs inside the safe area. Jump has a candy-corn stitch. The felt stick ring shows stitched
    chevrons.
  - Pause: night-violet scrim with a paper card; Resume is orange.
  - Pressing a button squashes it and darkens the felt.
- **Not built yet (no dead buttons).** These have no feature behind them yet:
  - notebook, settings, credits and language screens;
  - paper-bat counter;
  - captions;
  - reduced-motion setting.

## Evidence (CI run 31, software GL; not a device)

- Tests: EditMode 103/103, PlayMode 16/16, Visual 1/1.
  - New tests: sprite catalog, import settings, HUD sizes and safe area, one primary action per screen, scrim colour,
