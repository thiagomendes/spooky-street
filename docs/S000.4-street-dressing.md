# S000.4: original street set

Branch `feature/s000.4-street-dressing`. This replaces the last greybox visuals (ground, path, edge hedges, skyline)
with original assets.

## Assets

Built by `tools/blender/env/street.py` and exported with `env_export_street.py`, using the same conventions and the
fixed culling as the rest of the environment set. The review render, made from the re-imported FBX files, is
`docs/evidence/s000.4/street_review.png`.

| Asset | Size | Triangles | Texture |
|---|---|---|---|
| Lawn tile | 4 m | 128 | own `Lawn_*` |
| Stepping-stone path | 2 m strip | 585 | `Street_*` atlas |
| Sidewalk with kerb | 2 m | 324 | `Street_*` atlas |
| Leaf scatters | 3 variants | — | `Street_*` atlas |
| Boundary hedge | 6 m | 2.3k | `Street_*` atlas |
| Neighbour houses A, B, C | tower, gambrel, crooked | about 5k each | `Street_*` atlas |

## In game

- **Placement:** an engine-free table in `EnvironmentLayout` holds all 266 instances:
  - 195 lawn tiles;
  - a path from the porch to the gate;
  - a sidewalk run;
  - 26 boundary hedges closing the block (spec §4);
  - 5 neighbour houses facing the street;
  - 10 leaf scatters.
- **Collisions:** the greybox ground, path and hedges keep their colliders but render nothing, so the route is
  unchanged.
- **Draw cost:** the street root is statically batched; all 276 renderers are batched in CI.
- **Glow:** neighbour windows use a dedicated level of 0.9, so the attic window (4.0) stays the brightest point.
